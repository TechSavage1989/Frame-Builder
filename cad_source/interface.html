    For separate filaments or print settings, use the Frame or UV base downloads in Export. Spacing and margins do not include purge towers or toolhead clearance.

    Print and assemble the UV base

    1. Print all tiles UV face down on PEI, at 100% scale with supports off.
    2. Assemble the panel before installing it in the frame so the posts can flex.
    3. For a grid, join the tiles into full rows first, then join the rows.
    4. Start both posts together and push evenly, keeping the UV faces parallel, until both outside hooks engage.
    5. Check that the seam is fully seated and both faces align. Check for rocking and loose catches.
