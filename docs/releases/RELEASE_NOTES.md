# Frame Builder 3.51.15

A small visible update for testing the built-in updater from 3.51.14.

- Shows the installed desktop version beside the builder title. After updating, the header displays v3.51.15.
- Preserves the existing frame geometry, controls, exports, saved settings and updater behavior.

In 3.51.14, choose Help > Check for updates, then Download and Install and restart after saving your work. A fresh download, verified installation, visible relaunch, settings and shortcut preservation, file locking and rollback are required by the release workflow.

For a manual installation, extract the Windows ZIP and run Frame Builder.exe.

Windows x64 portable. The application is unsigned. Hosted Windows validation does not replace checking the update on your own PC. Mechanical geometry remains the accepted 3.51.6 baseline; no new physical print testing is included.
