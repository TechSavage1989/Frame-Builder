# Frame Builder 3.51.17

A small visible update for testing installation from 3.51.16.

- Renames the viewer heading from "3D model" to "3D preview" so the update is easy to recognize.
- Shows 3.51.17 beside the builder title after installation and restart.
- Keeps the installed filename "Frame Builder.exe", saved settings and shortcut targets. The versioned GitHub EXE is the download payload.

Update through Help > Check for updates, then Download and Install and restart. Confirm the restart prompt. For a manual installation, extract the Windows ZIP and run Frame Builder.exe.

This release changes only the viewer label and version. Model generation, exports and updater behavior are unchanged. It provides a fresh update for installation testing.

Windows x64 portable. The application is unsigned. Hosted Windows validation does not replace checking the update on your own PC. No new physical print testing is included.
