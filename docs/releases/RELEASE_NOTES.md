# Frame Builder 3.51.16

Smoother model editing and a cleaner workspace.

- Builds previews in a background worker so controls remain responsive during geometry generation. Rapid edits cancel superseded builds.
- Removes duplicate planning work, reduces temporary rendering allocations and combines repeated exploded-view slider redraws.
- Shortens export labels, removes duplicate viewer badges and keeps the title and installed version readable in narrow windows.
- Keeps the last valid preview visible while settings are corrected. Exports remain disabled until the current model is ready.
- Preserves all four frame styles, accepted geometry, saved settings and STL, STEP and 3MF exports. A cooperative fallback remains available when browser workers cannot start.

Update through Help > Check for updates, then Download and Install and restart. For a manual installation, extract the Windows ZIP and run Frame Builder.exe.

Windows x64 portable. The application is unsigned. Hosted Windows validation does not replace checking the update on your own PC. No new physical print testing is included.
